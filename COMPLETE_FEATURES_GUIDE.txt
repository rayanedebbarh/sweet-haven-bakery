## 📞 TESTING TIPS:

**If images don't show:**
1. Check that `images` folder exists
2. Make sure it's in the same folder as HTML files
3. Check file names match exactly (case-sensitive!)

**If cart doesn't work:**
1. Open browser console (F12)
2. Look for JavaScript errors
3. Make sure `cart.js` is in the same folder
4. Check that all HTML files have `<script src="cart.js"></script>`

**If checkout seems broken:**
1. It's working correctly!
2. The demo just shows an alert
3. Then redirects to home page
4. This is intentional (no real payment processing)
